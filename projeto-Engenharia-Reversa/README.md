# 🎨 QR Code Styling Clone - Gerador de QR Code Profissional

## 📝 Descrição do Projeto
Este projeto é um motor de geração e personalização de QR Codes de alta performance, inspirado na biblioteca `qr-code-styling`. O objetivo é permitir que usuários criem códigos visualmente impactantes que se integram perfeitamente a marcas e identidades visuais, superando a estética genérica dos QR Codes tradicionais.

Desenvolvido para oferecer uma experiência de **Vibecoding** fluida, o sistema permite ajustar em tempo real cada detalhe geométrico e cromático do código, garantindo a legibilidade através de algoritmos avançados de correção de erro (ECC Nível H).

## 🚀 Tecnologias Utilizadas
* **Framework:** React 19 + Vite
* **Estilização:** Tailwind CSS 4.0
* **Biblioteca Principal:** `qr-code-styling`
* **Ícones:** Lucide React
* **Animações:** Motion (Framer Motion)

## 📊 Funcionalidades e Diferenciais
O projeto alcançou uma fidelidade visual extrema, permitindo customizações que antes exigiam softwares de design gráfico.
* **Visualização Real-time:** Feedback instantâneo de cada alteração aplicada.
* **ECC Nível H (30%):** Configurado nativamente para suportar logos centrais sem perder o scan.
* **Personalização Atômica:** 
    * Ajuste de estilos de pontos (Dots, Rounded, Classy).
    * Customização independente de molduras (Corners Square) e centros (Corners Dot).
    * Suporte total a **Cores Gradientes** e transparências.
* **Integração de Imagem:** Upload de logos com remoção automática de pontos sobrepostos e ajuste de margem.

## 🔧 Como Executar
1. Clone o repositório.
2. Instale as dependências: `npm install`.
3. Inicie o servidor de desenvolvimento: `npm run dev`.
4. Acesse em seu navegador: `http://localhost:3000`.

## 📥 Opções de Exportação
O sistema suporta exportação de alta fidelidade para uso em diversos meios:
* **Formatos de Imagem:** PNG, JPEG e SVG (vetorial).
* **Configurações:** Possibilidade de exportar as opções atuais como um arquivo JSON para uso em outros projetos JS.

# 🎨 MYQRCODE CUSTOM - Gerador de QR Codes Artísticos
 
## 📝 Descrição do Projeto
Este projeto é uma ferramenta avançada de design generativo para QR Codes. O objetivo é transformar códigos QR funcionais em peças visuais esteticamente agradáveis, integrando logotipos, gradientes e formas customizadas sem comprometer a integridade da leitura por smartphones.
 
O sistema utiliza a biblioteca `qr-code-styling` e técnicas de **Design de Visão Computacional**, permitindo que o usuário ajuste o nível de correção de erro (ECC) para o Nível H (30%), garantindo que o código permaneça escaneável mesmo com interferências artísticas ou inserção de imagens centrais.
  
## 🚀 Tecnologias Utilizadas
* **Linguagem:** TypeScript
* **Framework:** React 18+ (Vite)
* **Estilização:** Tailwind CSS & Lucide React
* **Internacionalização:** i18next (Suporte multi-idioma)
* **Backend & Auth:** Firebase (Authentication e Analytics)
* **Motor de Renderização:** QR-Code-Styling
 
## 📊 Resultados e Aprendizados
O projeto foca na experiência do usuário e na precisão técnica para garantir que a arte não impeça a funcionalidade.
* **100% de Escaneabilidade:** Implementação de algoritmos de contraste dinâmico para garantir o scan em diferentes condições de luz.
* **Internacionalização:** O sistema foi estruturado para suportar mais de 8 idiomas, permitindo alcance global.
* **Otimização de Performance:** Utilização do Vite para um tempo de carregamento e resposta instantânea na pré-visualização.
 
## 🔧 Como Executar
1. Clone o repositório.
2. Instale as dependências: `npm install`.
3. Configure o ambiente do Firebase (opcional para auth).
4. Execute o comando: `npm run dev`.
